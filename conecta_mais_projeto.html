Projeto educativo desenvolvido com HTML, CSS e JavaScript.

Como usar o Conecta+

  • Toque em A+ para aumentar as letras.
  • Toque em A− para diminuir as letras.
  • Use Alto contraste para mudar as cores.
  • Toque em Ler página para ouvir o conteúdo.
  • Use Parar leitura para interromper a voz.
